Banding Parfum — Dataset & Skor Value

Membangun dataset 218 parfum dari 47 merek dengan script Python, lalu mengolahnya jadi skor yang bisa dibandingkan.

  • Scraping dan parsing data harga, varian, dan rating dari toko resmi brand, Tokopedia, Fragrantica, dan Female Daily.

IoT Deteksi Umur

Webcam laptop mendeteksi wajah dan memperkirakan umur. Hasilnya tampil di dashboard web dan di perangkat ESP32.

  • Deteksi wajah dengan YOLOv8n-face, estimasi umur dengan model age_net (Caffe) lewat OpenCV.
